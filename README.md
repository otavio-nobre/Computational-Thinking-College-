# Computational Thinking — College Exercises 🧠🐍

This repository contains Python solutions and algorithmic exercises developed for the **Computational Thinking** (*Pensamento Computacional*) course in the **BTI (Bachelor in Information Technology)** program at **UFRN**.

---

## 📂 Included Scripts & Topics

* **`cash_or_installment.py`**: Financial calculation logic evaluating cash discounts versus installment payment options.
* **`fatorial_of_a_number.py`**: Iterative or recursive logic for calculating the factorial of an integer.
* **`first_and_last_name.py`**: String parsing utility to extract and manipulate full names.
* **`second_biggest.py`**: Algorithmic script to find the second largest numerical value in a dataset/list.
* **`student_grading.py`**: Academic performance evaluation system processing student marks and grade classifications.
* **`temperature_scale.py`**: Temperature scale converter handling standard units (Celsius, Fahrenheit, Kelvin).
* **`types_of_triangles.py`**: Geometry classifier determining triangle validity and categorization (Equilateral, Isosceles, Scalene) based on side lengths and angles.
